Optional. Put `han.otf` (big characters, e.g. a Kaiti/brush or Noto Serif CJK SC Black font) and/or `ui.otf`
(all other text, e.g. Noto Sans CJK SC Bold) here, or pass --han-font / --ui-font.
The script embeds only the characters a quiz uses. Without these files the page uses the system fonts
(macOS: Kaiti SC / PingFang SC).
